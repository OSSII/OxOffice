## 特色

### 符合亞洲市場

支援全字庫自造字環境、預載各式中文開放字體，適用於中文環境及政府場域，另外針對中文亂碼、疊字及直書應用的部份都已進行調校作業，於中文文件排版相容性已大幅提昇，減少人工調整文件的時間成本。

晟鑫科技補足了官方版本在字型以及中文編碼不足的部分，針對此問題改善了華文地區使用者的操作環境，包括了字型預設大小設定、疊字問題、表格排版跨頁……等。

### 整合多項應用元件

OxOffice 整合自造字型、軟體客服支援、報表設計巨集、轉檔及線上編輯應用等平台及 API，並可介接開源雲端檔案系統系統、建置有效率的線上文件共同編輯環境及輸出標準的 ODF 報表格式檔案。

### 具商用文件格式轉 ODF 引擎

政府與民間企業運用開放原始碼的時代已經來臨，ODF 文件格式也已成為政府文書處理軟體的新標準，OxOffice 提供相容性高的 ODF 轉檔方案，更精準的轉檔結果，加速轉換過程，降低導入過程中的時間成本。

### 開源模式自由使用不受限

提供可自由運用的開放原始碼方案，讓企業不被單一特定廠商方案所限制，同時遵守各式開放文件、開放 API 標準，讓系統間彼此依照規範即可輕易整合介接，相關的程式碼也公開並開放讓各界參與貢獻。

### 具備商用支援服務

#### 軟體修正服務

OxOffice 提供官方版本所缺少的功能與軟體修正。

#### 整合軟體應用套件及相關資源

中文符號工具列、中文缺字字型配對機制、範本中心、應用軟體擴充功能、額外的圖庫、文件支援中心及預設範本等資源。

## 安裝

本產品的安裝方式：

### Windows

請於[本產品的釋出頁面](https://github.com/OSSII/OxOffice/releases)下載下列檔案名稱式樣之安裝包後點擊兩下進行安裝：

* （x86 處理器架構適用）OxOffice\_x86-_版本號_.msi
* （x86-64 處理器架構適用）OxOffice\_x86\_64-_版本號_.msi

### macOS

請參閱 [OxOffice Mac 版本安裝說明](https://docs.ossii.com.tw/books/oxoffice-mac)。
